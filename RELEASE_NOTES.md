# Release Notes

This public release is designed as a post-run, browser-local cognitive cartography instrument. It is suitable for research, accountability, evidence generation, and incident review.

Known boundaries:

- The public instrument is non-interventional and does not steer AI agents in real time.
- Full multi-manifold canonical mode requires supplied embedding trace, ensemble run, reference manifold, and calibration profile data.
- Transcript-only runs generate real computed runtime evidence, but operator provenance must be read as transcript-derived estimator mode.
- FieldLock real-time stabilization is not included in this public repository.
