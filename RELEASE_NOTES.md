# Release Notes

## Fieldglass® Runtime Evidence Observatory

**Public Beta v1.0**

Fieldglass® Public Beta v1.0 is the first public release of the Runtime Evidence™ platform and observatory.

This release introduces a browser-local runtime evidence workflow that transforms AI interaction logs into observable, replayable, challengeable, and preservable runtime evidence.

The public instrument is designed for:

* Runtime Evidence research
* AI safety investigation
* Incident review
* Accountability analysis
* Runtime observability experimentation
* Evidence generation
* EvidenceCommons® preservation workflows

# Known Boundaries

## Public Instrument Scope

The public instrument is observational and evidence-generating.

It is not an autonomous control system and does not intervene in running AI systems.

Fieldglass® observes, reconstructs, analyzes, and preserves runtime evidence.

It does not steer model behavior in real time.

---

## Transcript-Derived Runtime Evidence

Transcript-only runs generate real computed runtime evidence.

However, evidence derived solely from interaction traces should be interpreted as transcript-derived reconstruction rather than full-system observability.

Additional telemetry sources may improve evidence coverage and confidence.

---

## Advanced Instrumentation Modes

Some advanced Runtime Evidence capabilities require additional runtime data not present in standard transcripts.

Examples include:

* Embedding traces
* Ensemble execution traces
* Reference manifolds
* Calibration profiles
* External telemetry layers
* Extended replay metadata

These capabilities are outside the scope of the Public Beta release.

---

## FieldLock®

FieldLock® stabilization and active runtime intervention systems are not included in this public repository.

The Public Beta release focuses on:

* Observation
* Reconstruction
* Investigation
* Preservation
* Export

rather than runtime control.

---

# Claim Boundary

Fieldglass® computes observable runtime evidence from supplied logs and interaction traces.

Fieldglass® does not claim:

* Hidden-state access
* Consciousness detection
* Intent inference
* Personality diagnosis
* Truth adjudication
* Root-cause certainty
* Automated deployment authority

Runtime Evidence should be interpreted within its published claim boundaries.

---

# Privacy

Fieldglass® Public Beta executes locally within the browser.

No mandatory account creation is required.

No mandatory transcript upload is required.

Operators retain control of their evidence artifacts unless they choose to share or publish them.
