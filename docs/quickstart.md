# Quickstart

## 1. Open the Instrument

Open:

```text
index.html
```

in a modern browser.

No login, backend, upload, API key, or server is required.

## 2. Start with the Killer Demo

Use the Start page button:

```text
Load “The Failure Nobody Saw”
```

Then compute the run from Ingest → Blackbox.

## 3. Paste Your Own Log

Open:

```text
Ingest → Blackbox
```

Paste an AI interaction log, incident trace, workflow transcript, or operational log.

## 4. Review Preflight

Before compute, Fieldglass reports:

- detected log family
- adapter status
- operational world
- recommended path
- raw log preserved
- canonical turns produced

## 5. Compute Evidence

Click:

```text
Compute Fieldglass
```

## 6. Review Evidence

Use:

- Runtime Evidence
- Evidence State
- Regime Map
- Failure Timeline
- Failure Boundary
- Role Topology
- Runtime Replay
- Instruments
- Export
