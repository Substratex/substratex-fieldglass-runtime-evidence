# Evidence Exports

Fieldglass supports export artifacts for replay, audit, review, and challenge.

## Export Families

- Zero Substrate Format
- Evolution & Synthesis Layer
- Human Report
- Benchmark Bridge Appendix
- Runtime Vulnerability Report
- Evidence Commons Bundle

## Export Boundary

Projection and diagnostic instruments do not mutate canonical evidence.

Exports should be read as computed runtime evidence from observable interaction traces, not as hidden model-state inspection or provider-internal telemetry.
