# Fieldglass® User Manual

**Version:** Public Instrument Manual v1.0  
**Generated:** 2026-05-29T04:44:56Z  
**Instrument:** SubstrateX Fieldglass® standalone browser-local instrumentation suite

This manual explains how to use Fieldglass® from the Start page through ingestion, analysis, instrumentation, validation, replay, and evidence export.

Fieldglass® is a browser-local runtime evidence instrument. It transforms AI interaction logs, operational traces, and multi-agent transcripts into deterministic runtime evidence: ingestion, preflight, runtime telemetry, behavioral-state indicators, failure timeline, role/tool pressure, boundary formation, replay, and exportable evidence bundles.

## Core Principle

Fieldglass uses observable interaction evidence only.

It does not claim hidden-state access, consciousness detection, intent inference, truth adjudication, blame assignment, or provider-internal telemetry unless that telemetry is explicitly supplied by the operator.
