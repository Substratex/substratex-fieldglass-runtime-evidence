# Fieldglass Runtime Evidence 100 Card

## Telemetry Condition Instruments

Telemetry engine generates the signal. Condition instruments turn that signal into readable evidence.

## Core Pipeline

```txt
Raw Logs
↓
Step Parsing
↓
Feature Extraction
↓
Metric Normalization
↓
Composite Signal φ
↓
ZSF-Compatible Output
↓
UI Rendering
```

## Primary Feature Layer

```txt
Token entropy
Turn-to-turn drift
Baseline divergence
Repetition pressure
Length volatility
Reasoning density
```

## Worldline

```txt
instability(t) = weighted structural / lexical pressure
φ(t) = 1 - instability(t)
```

Higher φ = more stable. Lower φ = more unstable.
