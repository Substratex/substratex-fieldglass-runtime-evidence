# Ingestion Cheatsheet

## Preferred Format

```txt
Engineer:
Regression reproduced.

Tool:
Command executed.

Assistant:
Investigating root cause.
```

## Supported Families

- Native Fieldglass transcript
- GitHub / CI logs
- SIEM / Security incident
- Cloud / Infrastructure
- Jira / Workflow coordination
- Support / Customer incident

## Preflight Checks

- detected family
- adapter status
- operational world
- recommended path
- raw log preserved
- canonical turns produced
- telemetry turns
- readiness
