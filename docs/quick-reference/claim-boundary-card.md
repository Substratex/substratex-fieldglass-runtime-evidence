# Claim Boundary Card

Fieldglass uses observable interaction evidence only.

## Fieldglass Can Support

- runtime evidence review
- transcript-derived telemetry
- failure timeline reconstruction
- role/tool pressure analysis
- replayable evidence
- exportable artifacts

## Fieldglass Does Not Claim

- hidden-state access
- consciousness detection
- intent inference
- truth adjudication
- blame assignment
- exact hardware energy measurement
- provider-internal telemetry unless supplied
