# Killer Demo Script

## Opening

This is Fieldglass®, a browser-local runtime evidence instrument. It turns AI interaction logs into deterministic runtime evidence.

## Demo

We will run the canonical demo:

```txt
The Failure Nobody Saw
```

The case shows a system that appears healthy externally while runtime instability forms underneath.

## Operator Steps

1. Open Start.
2. Click Load “The Failure Nobody Saw”.
3. Move to Ingest / Blackbox.
4. Review preflight.
5. Compute Fieldglass.
6. Review Reveal.
7. Open Runtime Evidence.
8. Inspect Evidence State, Failure Timeline, Failure Boundary, Role Topology, and Runtime Replay.
9. Export the evidence bundle.

## Close

Fieldglass does not claim hidden-state access. It uses observable interaction evidence to reconstruct runtime behavior, failure formation, and replayable evidence.
