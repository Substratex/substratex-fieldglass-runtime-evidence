## Inspection Order

```txt
1. Locate stable temporal baseline.
2. Check compression.
3. Check shear.
4. Check echo-time.
5. Identify chrono-loop.
6. Compare with Failure Boundary.
7. Inspect role/tool amplifiers.
8. Replay the temporal path.
9. Export Chronos appendix.
10. Attach claim boundary.
```

## Core Rule

Chronos does not claim hidden model time. It reconstructs observable symbolic-time deformation from runtime evidence.
