# Claim Boundaries

Fieldglass uses observable interaction evidence only.

## Fieldglass Can Surface

- runtime instability
- lead-time
- basin formation
- failure chronology
- role/tool pressure
- temporal deformation
- runtime behavioral state
- evidence replayability
- export integrity

## Fieldglass Does Not Claim

- hidden-state access
- consciousness detection
- intent inference
- truth adjudication
- blame assignment
- model-weight inspection
- private activation access
- provider telemetry access unless explicitly supplied

## Export Rule

Diagnostic and projection instruments may enrich interpretation, but they do not mutate canonical evidence artifacts.

Canonical evidence remains governed by:

- Zero Substrate Format
- Evolution & Synthesis Layer
- deterministic identity
- replay metadata
- export integrity
