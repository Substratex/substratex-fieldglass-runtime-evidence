# Runtime Evidence Standard

Runtime Evidence is the public evidence category operationalized by Fieldglass® Runtime Evidence Observatory.

## Principle

```txt
AI systems should be assessed by observable runtime motion, not only by benchmark scores, outputs, dashboards, or institutional claims.
```

## Evidence families

```txt
runtime state movement
failure timeline
failure boundary / attractor containment
role topology
runtime replay
drift evidence
energetic pressure
noesis evidence
export artifact preservation
```

## Claim boundary

Runtime Evidence is observable-only. It does not claim hidden-state access, consciousness, intent, personality diagnosis, automated deployment control, or root-cause certainty.
