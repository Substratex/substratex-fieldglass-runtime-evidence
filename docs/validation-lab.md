# Validation Lab

The Validation Lab organizes representative operational worlds and failure modes.

Current validation categories:

- Monitoring Blind Spots
- Workflow Coordination
- Software Engineering
- Security & SIEM
- Cloud Infrastructure
- Attention Engine
- Determinism & Validation

## Purpose

Validation Lab helps operators test whether Fieldglass can ingest and compute evidence across realistic operational log families.

## Use

1. Open Validation Lab.
2. Select a scenario family.
3. Load or copy the scenario log.
4. Compute through Ingest → Blackbox.
5. Inspect Runtime Evidence and Export.
