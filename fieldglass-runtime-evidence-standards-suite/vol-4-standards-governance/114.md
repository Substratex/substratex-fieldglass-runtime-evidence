## Claim Boundary

This module is limited to observable runtime evidence derived from supplied logs, canonical turns, computed telemetry, replay metadata, and explicit reviewer markers. It does not claim hidden-state access, provider-internal telemetry, consciousness detection, intent inference, personality diagnosis, blame assignment, root-cause certainty, or automated deployment authority.

# Fieldglass Runtime Evidence 114: Evidence Commons Challenge Protocol

## Purpose

The Challenge Protocol defines how reviewers dispute, reproduce, compare, or refine a Fieldglass evidence case.

## Challenge Types

- Replication challenge
- Interpretation challenge
- Marker challenge
- Claim-boundary challenge
- Schema challenge
- Version-drift challenge
- Counter-analysis

## Challenge Workflow

```txt
Open case → verify identity → inspect raw input → replay evidence → inspect exports → submit challenge → preserve response → compare revisions
```

## Challenge Report

A Challenge Report SHOULD include:

```txt
challenge_id
case_id
challenger
challenge_type
claim_under_review
evidence_basis
counter_interpretation
requested_change
claim_boundary
```

## Evidence Appeals

No challenge should erase the original case. Appeals create linked evidence, not overwritten history.


## EvidenceCommons® Contribution

This module contributes its typed object, review guidance, and claim boundary to the EvidenceBundle.
