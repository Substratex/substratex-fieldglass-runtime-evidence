# Fieldglass Runtime Evidence 111: Claim Boundaries and Scientific Language

## Purpose

This module defines safe scientific language for Fieldglass, Runtime Evidence, EvidenceCommons, NOESIS, Chronos, Energetics, and related instruments.

## Evidence Language Tiers

```txt
Observable Evidence
Inference
Projection
Speculation
Prohibited Claim
```

## Observable Evidence

Use when directly grounded in supplied logs, canonical turns, computed telemetry, replay frames, or exported artifacts.

## Inference

Use when Fieldglass combines observable signals into an interpretation such as boundary proximity, runtime pressure, or role fragmentation.

## Projection

Use when an instrument visualizes possible structure, terrain, basin shape, or continuation posture.

## Speculation

Speculation MUST NOT be exported as canonical evidence.

## Prohibited Claims

Fieldglass public artifacts MUST NOT claim:

- hidden-state access
- consciousness detection
- sentience
- private memory access
- intent certainty
- personality diagnosis
- root-cause certainty
- deployment authority
- measured hardware energy without external telemetry

## Required Boundary Formula

```txt
This artifact reports observable runtime evidence and bounded diagnostic interpretation. It does not claim hidden-state access, intent inference, consciousness detection, root-cause certainty, or automated deployment authority.
```
