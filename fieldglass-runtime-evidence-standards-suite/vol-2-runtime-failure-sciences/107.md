## Purpose

Runtime Evidence 107 documents the operational evidence bridge between role topology and runtime replay. The section explains how role-bearing logs become evidence of coordination structure, authority pressure, handoff breakdown, tool-loop stress, observer divergence, and replayable incident sequence.

## Operator question

```txt
Which roles carried pressure, how did coordination change, and what sequence should be replayed for evidence review?
```

## Evidence flow

```txt
Role-bearing log
→ role extraction

→ authority / handoff / tool-loop evidence

→ exportable incident reconstruction
```
